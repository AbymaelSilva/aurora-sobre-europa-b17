# Aurora sobre Europa — B-17 Flying Fortress
## Versión Portable para ASUS ROG Ally, ROG Ally X y Windows x86-64

¡Bienvenido a los cielos de Europa en el invierno de 1945!

Esta edición está compilada y optimizada para dispositivos portátiles con Windows (ASUS ROG Ally, ROG Ally X) y PCs con mando Xbox / XInput. No requiere instalación: es completamente **portable**.

---

### Requisitos del Sistema

* **Sistema Operativo:** Windows 10 / Windows 11 (64 bits).
* **Dispositivo:** ASUS ROG Ally / ROG Ally X, o cualquier PC Windows con mando compatible tipo Xbox (XInput).
* **Resolución recomendada:** 1280×720 (720p nativo) o 1920×1080 (1080p).
* **Espacio en disco:** ~220 MB libres.

---

### Cómo Iniciar el Juego

1. Extrae todo el contenido de la carpeta ZIP en cualquier directorio de tu dispositivo.
2. Ejecuta haciendo doble clic en **`AuroraSobreEuropa.exe`**.
3. El juego detectará automáticamente tu mando incorporado / controlador Xbox.

---

### Guía de Controles — Perfil Mando ROG Ally / Xbox

| Acción | Mando ROG Ally / Xbox | Teclado / Ratón |
|---|---|---|
| **Alternar 3ª / 1ª Persona** | **Botón `Y`** | Tecla `V` |
| **Orbitar Cámara Exterior** | **Stick Derecho** | Mantener Clic Derecho + Mover Ratón |
| **Recentrar Cámara a la Cola** | **Pulsar Stick Derecho (`R3`)** | Tecla `C` |
| **Zoom de Cámara (45 m a 320 m)** | **`LB` + Cruceta Arriba / Abajo** | Rueda del Ratón |

| **Piloto Automático (ON / OFF)** | **Botón `View` / `Back`** | Tecla `TAB` |
| **Control de Vuelo (Alabeo / Cabeceo)** | **Stick Izquierdo** *(en puesto Piloto sin autopiloto)* | Teclas `W`, `A`, `S`, `D` |
| **Potencia / Acelerador** | **Gatillos `RT` (acelerar) / `LT` (frenar)** | `Shift` / `Control` |
| **Puesto: Piloto (Cabina)** | **Cruceta Arriba** | Tecla `1` |
| **Puesto: Artillero (Torreta)** | **Cruceta Derecha** | Tecla `2` |
| **Puesto: Bombardero (Visor)** | **Cruceta Abajo** | Tecla `3` |

| **Menú de Pausa y Ajustes** | **Botón `Menu` / `Start`** | Tecla `Escape` |

### Notas de Jugabilidad

* **Piloto Automático:** Al iniciar o al cambiar a observar a un compañero, el piloto automático se activa automáticamente para proteger la formación. Presiona **`View / Back`** (o `TAB`) para tomar el timón manual en cualquier momento.
* **Cámara en 3ª Persona:** Puedes volar y observar el combate completo desde el exterior. Para recentrar la vista inmediatamente detrás de tu B-17 pulsa **`R3`** (o tecla `C`).
* **Audio y Voces:** Todas las conversaciones de tripulación están en inglés de época con subtítulos localizados al español. Los controles de volumen de música, efectos y voces son accesibles desde el menú de pausa.
